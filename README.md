# WireLens

An HTTP(S) debugging, interception and mocking tool for Windows and Android. WireLens is a
rebranded fork of [HTTP Toolkit](https://httptoolkit.com) (AGPL-3.0). See [NOTICE.md](NOTICE.md).

Compared with upstream, WireLens:

- **Runs fully locally.** The desktop app serves the web UI from `127.0.0.1:28080` instead of
  loading `app.httptoolkit.tech`, and the server only accepts that loopback origin plus a
  per-launch auth token.
- **Has no accounts, billing or telemetry.** All features are enabled with no login. Sentry
  and PostHog only run if you set `SENTRY_DSN` / `POSTHOG_KEY` yourself.
- **Never self-updates from upstream.** The oclif update plugin is removed, the server never
  downloads HTTP Toolkit releases, and the Android app's GitHub update check is off.
- **Keeps its data separate.** Its own CA ("WireLens CA") and config live in
  `%LOCALAPPDATA%\wirelens`, its control pipe is `\\.\pipe\wirelens-ctl`, and its Android
  package is `dev.wirelens.android`, so it can sit next to a real HTTP Toolkit install.
- **Ships its Android app.** ADB interception installs the APK bundled with the desktop app.

## Layout

| Folder | What it is |
|---|---|
| `desktop/` | Electron shell (window, local UI server, server lifecycle) |
| `server/`  | Node server: Mockttp proxy, CA, interceptors (browsers, terminals, Docker, JVM, Android, Frida) |
| `ui/`      | React web UI (View / Modify / Send / Intercept / Settings) |
| `android/` | Android VPN client (QR & ADB pairing, SPKI-pinned proxy check) |
| `scripts/` | Build & staging scripts, logo generator |

Special hostnames answered by the proxy itself: `amiusing.wirelens.internal` (interception
check and `/certificate`) and `android.wirelens.internal` (`/config`, `/connect`).

## Building (Windows)

Prerequisites: Node 24, Git, JDK 21, and the Android SDK (platform 37, build-tools 37).

```bash
# 1. Install dependencies (npm 12 blocks install scripts; see "Native modules" below)
cd ui && npm ci && cd ..
cd server && npm ci --ignore-scripts && npx tsx ./prepare.ts && cd ..
cd desktop && npm ci --ignore-scripts && node node_modules/electron/install.js && cd ..

# 2. Android APK (signed with android/keystore.properties, if present)
cd android && ./gradlew.bat assembleRelease && cd ..

# 3. Build server + UI, stage them into desktop/, and build the installer
node scripts/build-all.mjs --package
```

Run without packaging: `node scripts/build-all.mjs`, then `npx electron .` in `desktop/`.

**Native modules.** `registry-js`, `win-version-info` and `node-datachannel` need compiled
`.node` binaries (N-API). Without a Visual Studio C++ toolchain they can't be built from
source. Either install the VS Build Tools and run each module's install script, or copy the
matching prebuilt binaries into `node_modules/<module>/build/Release/`.

**Branding assets** are generated by `python scripts/make-logo.py` (needs Pillow).
